# PinPay - 位置記帳 WebApp

結合 GPS 定位與快速記帳的 Progressive Web App。

## 功能特色

- 📍 **GPS 定位** - 自動記錄支出發生的位置
- 🗺️ **Google Maps 整合** - 支援 Google Maps 分享連結匯入
- 📸 **照片記錄** - 拍攝或上傳收據、簽單照片
- 💰 **快速記帳** - 簡潔的介面，快速完成記帳
- 👥 **分帳功能** - 支援多人分帳計算（平均、自訂、百分比）
- 💸 **結算管理** - 追蹤欠款與還款狀態
- 📊 **統計圖表** - 支出趨勢、分類分布、月度統計
- 💾 **資料匯出** - 支援 CSV、JSON 格式匯出與匯入
- 🔒 **本地優先** - 資料儲存於瀏覽器，無需網路即可使用
- 📱 **PWA 支援** - 可安裝到手機桌面

## 技術棧

- **前端框架**: React 18 + TypeScript
- **建構工具**: Vite
- **樣式方案**: Tailwind CSS
- **狀態管理**: Zustand
- **本地儲存**: IndexedDB (Dexie.js)
- **路由**: React Router v6
- **PWA**: Vite PWA Plugin

## 使用說明

### 記帳流程

1. 點擊底部導航「記帳」按鈕
2. 輸入金額
3. 選擇類別（餐飲、交通、購物等）
4. 選擇支付方式
5. （選填）使用 GPS 定位或貼上 Google Maps 連結
6. （選填）拍攝或上傳收據照片
7. （選填）添加備註
8. 完成記帳

### GPS 定位

點擊「使用 GPS 定位」按鈕，瀏覽器會要求定位權限。授權後會自動獲取當前位置。

### Google Maps 連結

1. 在 Google Maps 中點擊分享
2. 複製連結
3. 在記帳頁面點擊「Google Maps 連結」
4. 貼上連結並點擊解析

支援的連結格式：
- `https://maps.google.com/?q=25.0330,121.5654`
- `https://www.google.com/maps/place/.../@25.0330,121.5654`
- `https://www.google.com/maps?ll=25.0330,121.5654`

### 照片上傳

- **拍照**: 使用相機直接拍攝收據
- **選擇照片**: 從相簿選擇已有照片
- 每筆記錄最多 5 張照片
- 照片會自動壓縮以節省空間

### 分帳功能

#### 創建分帳記錄

1. 在記帳頁面開啟「需要分帳嗎？」開關
2. 點擊「新增參與者」或選擇常用參與者
3. 選擇誰付款
4. 選擇分帳方式：
   - **平均分攤** ⚖️ - 自動平均分配給所有人
   - **自訂金額** ✏️ - 手動輸入每人應付金額
   - **百分比** 📊 - 輸入百分比自動計算金額
5. 完成記帳

#### 管理分帳記錄

1. 點擊底部「分帳 👥」頁籤
2. 查看所有分帳記錄與統計
3. 點擊記錄查看詳細資訊

#### 結算管理

1. 在支出詳情頁查看「分帳明細」
2. 在「結算管理」區域標記已還款
3. 系統自動追蹤欠款狀態
4. 所有人還款後自動標記為「已結清」

### 統計圖表

1. 點擊底部「統計 📊」頁籤
2. 選擇時間範圍（最近 7 天、最近 30 天、全部）
3. 查看以下統計資訊：
   - **摘要卡片** - 總支出、總筆數、平均金額、最大單筆
   - **月度比較** - 本月與上月的支出對比
   - **每日趨勢** - 線圖顯示支出變化
   - **分類分布** - 圓餅圖與詳細列表
   - **月度統計** - 近 6 個月的支出長條圖
   - **支付方式** - 各支付方式的金額分布

### 資料匯出與匯入

在「設定 ⚙️」頁面：

#### 匯出功能
- **CSV 格式** - 適合 Excel 分析，包含所有記帳欄位
- **完整備份 (JSON)** - 包含所有資料（照片、GPS、分帳等）
- **分帳記錄 (CSV)** - 專門匯出分帳明細

#### 匯入功能
- 選擇先前匯出的 JSON 備份檔案
- 可恢復所有記帳資料
- ⚠️ 匯入會覆蓋現有記錄，請謹慎操作

## 資料儲存

所有資料儲存於瀏覽器的 IndexedDB 中，不會上傳到伺服器。

⚠️ **注意**: 清除瀏覽器資料會刪除所有記錄，請定期備份重要資料。

## 瀏覽器支援

- Chrome/Edge: 最新 2 個版本
- Safari iOS: 14+
- Firefox: 最新 2 個版本
